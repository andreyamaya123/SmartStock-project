# SmartStock

Sistema de gestión de inventario desarrollado con Django y Docker.

## Tecnologías utilizadas

- Python
- Django
- Bootstrap
- Docker
- Docker Compose
- SQLite

---

## Funcionalidades

- CRUD de productos
- Dashboard de inventario
- Sistema de autenticación
- Diseño responsive
- Gestión de stock

---

## Ejecutar proyecto

### Requisitos

- Docker Desktop

### Instalación

```bash
docker compose up --build
```
